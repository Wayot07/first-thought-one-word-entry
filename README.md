# One Word, First Thought — `quicksilver`

An entry for the make.fun competition
[u-0xkianno-one-word-first-thought-106abaf8](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8):
send exactly one word — the first that comes to mind. No topic, no
explanation, no second draft.

The word is **quicksilver**: liquid mercury that will not sit still, and a
temperament just as mercurial. Surprising, vivid, and double-edged — it
rewards a second look.

## Run

Requires Node.js 22+ (stdlib only, no dependencies):

```sh
node --experimental-strip-types main.ts
```

This writes the single word to `/output/entry.txt` — exactly 11 bytes,
no whitespace, no trailing newline — and verifies the file on disk is
byte-identical to the word. Any gate violation fails fast (stderr + exit 1).
